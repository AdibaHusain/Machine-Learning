Aap optimizers ko **"pahad se niche utarne wale bande"** wali story se yaad rakh sakte hain. 🎯

Imagine karo aap mountain ke top par ho aur niche valley me jaana hai. Valley = minimum loss.

---

# 1. Gradient Descent (GD)

### Kaise kaam karta hai?

Pure dataset ko dekh kar ek step leta hai.


### Example

Agar 1 lakh images hain, to pehle sab 1 lakh images par loss calculate karega, phir ek update.

### Pros

✅ Stable updates
✅ Smooth convergence

### Cons

❌ Bahut slow
❌ Large dataset par expensive

### Visualization

```
Dataset: [100000 samples]

Calculate gradient on ALL samples
        ↓
Update weights
```

---

# 2. Stochastic Gradient Descent (SGD)

Problem:
GD bahut slow tha.

Solution:
Ek hi sample dekh kar update kar do.

### Example

```
Sample 1 → update
Sample 2 → update
Sample 3 → update
...
```

### Pros

✅ Fast learning
✅ Less memory

### Cons

❌ Bahut noisy updates
❌ Loss zig-zag karta hai

### Visualization

```
GD:
-------->

SGD:
\/\//\/\//\/\
```

SGD valley ki taraf jaata hai but bahut hilte-dulte hue.

---

# 3. Mini-Batch SGD

Practical duniya me mostly ye use hota hai.

Pure data nahi,
1 sample bhi nahi.

Batch size = 32, 64, 128 etc.

```
64 samples
    ↓
Update

Next 64
    ↓
Update
```

Ye SGD ka hi practical version hai.

---

# 4. Momentum

Problem:
SGD zig-zag kar raha tha.

Idea:
Pichli direction bhi yaad rakho.

### Real Life Analogy

Football ko kick maarte ho.

Ball har second ruk kar direction decide nahi karti.

Usme momentum hota hai.

### Pros

✅ Faster convergence

✅ Less oscillation

### Visualization

```
SGD:
\/\/\/\/\/\/

Momentum:
\_________
```

Momentum slope ke along speed build karta hai.

---

# 5. AdaGrad

Problem:
Sab parameters ko same learning rate mil raha hai.

Idea:
Har parameter ka apna learning rate.

### Kaise?

Jo feature bahut frequently update ho raha hai,
uski learning rate kam kar do.

Jo rarely update ho raha hai,
uski learning rate zyada rakho.

### Pros

✅ Sparse data ke liye amazing

(NLP me kaafi useful tha)

### Cons

❌ Learning rate continuously chhoti hoti jaati hai

Eventually almost zero.

Training ruk sakti hai.

### Visualization

```
Learning Rate

0.1
0.08
0.05
0.02
0.005
0.0001
```

---

# 6. RMSProp

Problem:
AdaGrad ki learning rate bahut jaldi zero ho rahi thi.

Solution:
Purani history sab mat rakho.

Sirf recent gradients yaad rakho.

### Pros

✅ Learning rate zero nahi hoti

✅ Faster convergence

### Cons

❌ Momentum jitni direction memory nahi

---

# 7. Adam (Most Popular)

Adam =

**Momentum + RMSProp**

Dono ke best features combine.

### Adam kya rakhta hai?

#### First Moment

Gradient ki direction
m_t
(Momentum)

#### Second Moment

Gradient ki magnitude
v_t
(RMSProp)

### Update

## Adam ko yaad kaise rakhein?

### Momentum

"Main kis direction me ja raha tha?"

### RMSProp

"Kitni badi step leni chahiye?"

### Adam

"Dono yaad rakho."

# One-Line Memory Trick

| Optimizer      | Main Idea                          |
| -------------- | ---------------------------------- |
| GD             | Pure dataset dekh ke update        |
| SGD            | Har sample pe update               |
| Mini-Batch SGD | Chhote batches pe update           |
| Momentum       | Pichli direction yaad rakho        |
| AdaGrad        | Har parameter ki alag LR           |
| RMSProp        | Recent gradients se LR adjust karo |
| Adam           | Momentum + RMSProp                 |

### Interview me ek line:

> **Gradient Descent stable but slow tha → SGD fast but noisy tha → Momentum ne direction memory di → AdaGrad ne adaptive learning rates diye → RMSProp ne AdaGrad ki shrinking LR problem solve ki → Adam ne Momentum aur RMSProp combine karke most effective optimizer bana diya.**
